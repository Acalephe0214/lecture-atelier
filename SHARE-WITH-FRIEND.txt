Lecture Atelier（听课之间）· 快速开始

本地录音转写、校对和笔记工具。
1. 完整解压 ZIP，先打开 START-HERE.html，再按“完整中文手册”或
   “Complete English manual”阅读。前四节是解压、安装、启动和第一段录音。
2. Mac 打开 .app / launch.command；Windows x64 打开 launch-windows.bat。
3. 基础模式不装依赖包或模型；仅在缺 Python 时确认运行环境下载。
   以后需要 PDF 或语音再打开 setup，选 2/pdf、3/speech 或 4/full。
   语音模式可能下载 0.5–1.5 GB、需 2–4 GB 磁盘；已有语音配置会保留。
4. 以后 Mac 双击 launch.command，Windows 双击 launch-windows.bat。
   在运行服务的终端按 Control+C 停止程序。
5. 转写是本地的；AI 校对/总结需要你自己的模型 API，Notion 也需你自己的
   connection。每次发送文字前会单独确认。页面可切换 English / 中文。
6. 安装不成功先看手册“故障排查”，不要删除 .runtime、关闭系统防护或
   不停重跑付费请求。需要协助时给系统版本和已脱敏错误，别发密钥或录音。

完整手册还包括：有稿/无稿两条路线、语言选择、回听与局部补转、降噪、
API 根地址/模型 ID/密钥怎么填、AI 修订接受/拒绝、总览失败诊断、Word/PDF/
字幕导出、Notion 授权、数据备份与升级。没有 API key 可先做本地处理。

Mac 的 .app 是未签名启动器，不要单独移出文件夹。如果系统拦截，请先检查
来源，不要关闭系统安全保护。Windows 脚本尚未经过 Windows 真机测试。
首次下载模型失败仍可用基础编辑与 PDF；可重试安装。不承诺 small 模型的
课堂专业术语识别准确率；结果须核对。

If using Codex: open the extracted folder and ask it to read AGENTS.md and
CODEX_SETUP.md. Ask it to install only project-local dependencies, verify the
basic server and then test local Whisper with synthetic speech. No recording
uploads, paid API calls, system-security changes or overwriting existing data.
