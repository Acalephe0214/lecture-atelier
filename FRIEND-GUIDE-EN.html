01 / Unzip before running anything

  1. Extract the whole ZIP. On Mac, double-click it in Finder. On Windows, use Extract All. Inside the extracted LectureAtelier folder you should see app.py, static, START-HERE.html and the setup scripts.
  2. Keep the entire folder in a writable, fixed location, such as Documents. Do not run inside the ZIP, move the .app out alone, or overwrite an existing installation.
  3. Allow space and internet access. Initial downloads are roughly 0.5–1.5 GB; reserve 2–4 GB disk. GitHub, PyPI and Hugging Face must be reachable. Download size and duration vary; no fixed completion time is promised.
  4. You do not need the author's account. Local use needs no Codex subscription, administrator rights or API key. Cloud features require your own accounts only if you choose to use them.

The installer provides multilingual CPU faster-whisper small for Mac (Apple Silicon or Intel) and Windows 10/11 x64. Windows ARM64 is not packaged. Windows scripts are supplied but have not been verified on a Windows machine. Existing Apple Silicon MLX settings are retained; the installer does not forcibly replace them.

02 / First setup: normally only once

Mac: use Finder

  1. Double-click setup-mac.command in the extracted folder. It should open Terminal, not merely show code in an editor.
  2. Read the download notice. If you trust the source and want the downloads, type y at [y/N] and press Return. Otherwise type n to decline.
  3. Keep the network and Terminal open. Setup reuses compatible Python or downloads a SHA256-checked project-local Python, then installs PDF/audio/Whisper dependencies and model weights. It does not change system Python or upload recordings.
  4. After success, the workspace opens in your browser. If not, manually visit http://127.0.0.1:8767/?ui=en. Keep the service Terminal open.

If double-clicking shows source code, return to Finder and choose Open With → Terminal. Alternatively open Terminal, type zsh including the trailing space, drag setup-mac.command into the window, then press Return. Do not paste the script's contents as instructions.

Windows: use the extracted folder

  1. Double-click setup-windows.bat. Enable File name extensions in Explorer if you cannot distinguish it from a document.
  2. Type y and press Enter when asked about downloads. Wait for project-local Python, dependencies and the model; do not close the command window midway.
  3. The app starts after successful installation. Open http://127.0.0.1:8767/?ui=en manually if needed and keep the command window open.
A security block is not an instruction to disable protection. The Mac .app is an unsigned launcher, not a notarized, self-contained native app. If Gatekeeper, SmartScreen, antivirus or PowerShell policy blocks execution, verify the source and retain the exact message. Do not disable protection, remove quarantine, bypass execution policy or run administrator commands. Ask the sender or your setup assistant to investigate.

If setup stops midway

Read the last error first. After restoring connectivity, rerun the same setup; it reuses dependency markers and download caches where possible, but not every interrupted download resumes in place. If only the model download failed, Python/PDF dependencies may already work: try launch for importing, reading and editing. Speech requires complete weights; PDF requires its dependencies. Never delete .runtime as a repair step.

If compatible Python 3.10+ already exists, you can try the basic app through launch without installing speech. Full setup uses Python 3.10–3.13; 3.12 is the main test baseline. Installation success is not proof that speech inference works on your machine.

04 / First session: choose your route

Start small: use Explore fictional demo to check reading and editing, then try a 30–60 second recording you are authorized to use—not a two-hour lecture first.

  1. Select a course on the left, add a session and fill its title/date. A fresh workspace has one generic Sample course category and no real sessions or author's course directories. Use Add course for your own categories. The demo button creates at most one fictional session, shared across UI languages; switching languages does not rewrite saved content.
  2. Use Add audio in the central panel. This imports into the local app, not a model vendor's cloud. Ordinary uploads save a local copy; indexed files remain at their external paths.
  3. Select the actual recording language: Chinese, English, Vietnamese, French, German, Japanese, or another supported code. For bilingual audio, use the French + Vietnamese preset, or choose Multilingual recording and select 2–6 languages. Enter other supported codes, e.g. es, in that dialog. This applies to the recording, not note output language.
Multilingual recordings: 12-second cores choose among candidate languages from audio, with 1-second context cropped using real word timestamps. The original language is retained, not translated. Legacy Chinese/English uses this path too. This adds local computation. Scores are heuristics, not a guarantee for rapid within-sentence mixing; weak evidence becomes a listening gap, with no invented speech or automatic cloud fallback. For a failed passage, temporarily select its single language, retry that passage, then restore the combination; no full rerun is needed. French/Vietnamese has synthetic routing and UI checks only so far; test permitted short real audio before relying on it.
Local MP4 / MOV / WEBM transcription: the first audio track is extracted and cached as 16 kHz mono WAV before Whisper starts. Progress first shows audio extraction. No lossy MP3 step, original replacement or removal of leading silence is used. Full retries and passage repair can reuse a valid cache; changing the original invalidates it. Allow roughly 110 MiB per hour of cached audio. Missing tracks/FFmpeg or insufficient disk space stop preparation before inference. This may reduce repeated decoding, but no overall speedup is guaranteed. External cloud transcription does not automatically use this local step.

A. You already have a transcript

  1. Use Import transcript for TXT, SRT, VTT or a compatible segments JSON. Check exports from other tools before importing.
  2. Untimed TXT works for reading/editing/summarizing, but cannot guarantee precise audio seeking or subtitle export. Keep an original SRT or timestamped JSON if available.
  3. The app does not automatically retranscribe the whole recording. Automatic sample-based comparison and selective fusion of an external transcript with local recognition is not fully implemented.

B. You have audio only

  1. Complete model installation and check the saved local environment in Settings. Setup usually fills the local model paths; do not copy the author's paths.
  2. Choose local Whisper transcription and approve local processing. Word alignment, silence-hallucination suppression, repetition and collapsed word-time checks are enabled. They add computation; real-time completion is not guaranteed.
  3. Inspect the transcript and gap report. A bad tail no longer discards independently validated earlier sentences; uncertain intervals remain explicit gaps, not a claim of silence. Processed blocks and blocks without detected issues are shown separately. If interrupted with saved chunks, use resume / reuse-good-chunks before repeating the entire session. Passage repair supports up to 64 passages and 30 minutes per queue, sequentially with cancellation. Listen and adopt candidates yourself; existing text is not automatically overwritten.

M4A, MP3, WAV and decodable QuickTime audio are accepted. QTA / QAT support depends on actual container contents, not its extension. Browser playback and model decoding are separate. For a problematic iPhone recording, export an ordinary M4A and retain the original; simply renaming the file is not conversion.

05 / Listen, repair gaps and denoise

  1. Listen: real timestamps allow seeking. Use pause/resume, speed and looping; the bottom playback dock can pause audio at any time.
  2. Fill a gap: open the passage's edit/listen control, type what you actually hear and explicitly resolve its gap marker. Do not reconstruct speech from an AI summary.
  3. Retry a passage: use the alternate-strategy repair control. Progress shows processed/total passages, the current passage and time range, strategy attempt, elapsed times and ready/failed/applied counts. It does not estimate completion from elapsed time. Each ready candidate has an Apply to transcript button: it replaces only that passage, retains history and remains unreviewed. Apply while other passages continue, or use Listen and compare candidate first. Failed passages have no apply button. Ready candidates survive cancellation/interruption. Edited sources or changed audio block stale replacements. Attempts are bounded, not an endless loop until something looks plausible; failed passages remain marked.
  4. Paragraph reading: groups presentation only; source IDs and timestamps remain. Expand or switch to the sentence timeline for detailed editing.
  5. Listening versions: generate light denoising, then select original or processed audio. Keyboard-click reduction is experimental and may weaken consonants. Default setup includes FFmpeg-related components; ordinary use does not require installing Homebrew. Original audio is never overwritten.

Repetition checks do not prove transcription accuracy. Even unflagged text can miss a negation, number or name. Verify important facts by listening.

07 / Two different AI tasks

AI proofread: suggest transcript edits

  1. Click AI proofread beside the transcript. Add topic/terms, e.g. project review, user experience, performance testing and improvement plans. Context is a hint, not a command to force those words into speech.
  2. After text-send consent, deletions use strikeout and additions another color; uncertain changes require review.
  3. Accept/reject individual edits or use bulk controls. Check numbers, negations, names and decisions first; do not accept everything blindly. A small class of in-word repeats may be auto-cleaned with undo.
  4. Listen or locally retranscribe uncertain audio; do not let text-only reasoning fill missing speech. Changed text may mark linked reviewed notes for re-review.

Choose note output language first

Note output language offers Chinese, English, French, German, Vietnamese, Japanese or Match source; Chinese remains the backward-compatible default. It is independent of UI and recording language and saved per session. Language settings shows the actual output rules and localized default scene prompt. Saving does not call a model or rewrite existing content. Custom prompts are preserved verbatim; edit them yourself when needed, while output-language rules still apply to the next generation. Generated titles, prose, overviews and actions use the target language; verbatim evidence quotes, JSON keys and source IDs stay unchanged. Proofreading still edits the original language rather than translating it. Overview-only generation does not translate existing detailed notes. Quality depends on your model and requires review; fixed UI/export-template labels still depend on interface/export language.

Compare task estimates correctly

Estimates separate detail extraction from overview synthesis. Overview-only retains detailed notes. Untouched, unreviewed source-copy cards become reference indexes for the request: full source text remains, without duplicate copied prose. Human-edited or verified notes remain verbatim; uncited source passages are included too. First-pass grouping matches execution; known call-limit and source problems block the task before model calls. Full runs regenerate details, whose future length is unknown, so their overview estimate uses current notes or source groups as a reference. Later calls, reasoning and costs may differ or exceed the range. Estimates are not budget caps and do not guarantee overview-only is always cheaper.

AI overview and detailed notes: organize the content

  1. Select the output mode—course study, lecture, classroom discussion, meeting minutes or custom—and inspect/edit its prompt. Meetings emphasize decisions/actions; lectures emphasize concepts/arguments.
  2. Click AI overview and detailed notes, then review external-send and usage confirmations. Extraction runs in batches before global synthesis. Progress shows stage, elapsed time, requests, streamed characters and provider-reported tokens.
  3. Read Overview and Detailed notes. The overview separates key information, final decisions, actions and unresolved issues with source links. Traceability is not semantic verification.
  4. Have notes but no overview? Use Generate overview only. This generates an overview while retaining notes; it does not mean “skip the overview.”

If generation fails

Existing notes and any previous overview remain. No paid request is automatically retried. Check whether the cause is truncation, empty output, JSON or evidence validation. New failures offer a local diagnostic download that may contain answer text—keep it private. Clicking generate again makes a new potentially billable request. Old discarded responses cannot be recovered. Do not repeatedly run an entire lecture merely to test a button.

Other tools → Verbatim copies just copies source text into cards. It is not AI proofreading, a summary or an original-transcript backup. Use TXT / SRT export if you only need the transcript.

Listen and edit, then export readable paragraphs

Every paragraph in the reading view has a visible Listen and edit button, including unflagged passages. Pause, change speed or play from a sentence, then edit its field. Sentence fields preserve real timestamps and source IDs; untouched sentences stay unchanged. Saving retains initial text and edit history, marks changed sentences unreviewed and linked verified notes for review. No AI or recognition is run. If a retry or another window has updated the same source, saving refuses to overwrite it and keeps your typed edits available to copy.

Export transcript editions defaults to Reading: merged paragraphs for Word, PDF, HTML, Markdown and TXT. Optionally show paragraph start times or choose the sentence Timeline layout. Grouping uses pauses, speakers and length without rewriting words; gaps remain separate. This is a reading-layout heuristic, not guaranteed semantic paragraph segmentation. Quick TXT export uses merged paragraphs too. SRT always retains sentence timestamps; JSON retains every source row and paragraph mapping.

Original means the snapshot before that proofreading pass. Marked includes accepted/pending changes, excluding rejected ones. Revised applies accepted edits only. Word, PDF, HTML, Markdown, TXT and JSON are available; SRT supports original/revised only. Word uses native tracked changes and colors may follow reader settings. Look in browser downloads / your Downloads folder. Local exports do not call a model.

Optional one-way Notion export

  1. In Rates & Notion, use the connection creation link and create your own write-enabled internal connection/integration under Notion's requirements. Keep its token private.
  2. Add it under the target parent page's Connections; a token alone is insufficient.
  3. Enter the parent page link/ID and Connection token in the app. This is not the LLM key. Saving settings sends no content.
  4. Use Send to Notion, check the target/content and approve. Each export creates a new child page; it is not two-way sync and does not update previous exports.
  5. If a previous result is unknown/partial, check Notion first before retrying to avoid duplicate pages.

Only overview/notes are sent—not audio or the full transcript. Notes can still quote source passages, so this is a cloud disclosure of session text.

09 / Data, backups, updates and sharing

  • Private data: hidden .runtime stores the database, uploaded audio, caches and private settings. Do not delete it to fix errors or send it to friends.
  • Downloads: models holds weights; .portable holds the project environment. The ZIP is small because these are downloaded on first setup.
  • Back up: finish tasks, stop with Control+C, then copy your complete used folder including hidden files. Mac Finder: Command+Shift+Period shows them. Back up indexed external sources separately.
  • Update: back up first; extract the new release to a new folder rather than overwriting the old one. Test a clean copy first. Ask an experienced helper/Codex to inspect before migrating .runtime: it contains keys and old absolute paths. Check model/external-source paths after moving. Never copy another user's .runtime.
  • Share: forward the clean distribution ZIP, not your used directory. Your exports, diagnostics and screenshots may contain private information and need separate review.
  • Not a shared website: 127.0.0.1 means the current computer. Sending that URL does not share your workspace. Keep the app loopback-only.

10 / Troubleshooting

Launch opens code / the URL starts with file://

Run the script in Finder/Explorer, not a chat file preview. On Mac use Open With → Terminal. Only this guide and Start here are standalone HTML; the actual workspace is http://127.0.0.1:8767/, not static/index.html.

Connection refused / the workspace will not open

Check the service Terminal; restart with launch if stopped. If installation failed, inspect its last error first. You do not need a public domain or a 0.0.0.0 listener.

Port busy / repeated windows

Check the existing URL and Terminal first. Do not keep launching copies or kill every Python process. If another application owns the port, have a helper choose an unused one. Do not run two services against the same database.

Downloads stall / PyPI or Hugging Face is unreachable

Keep the exact error, check official-source connectivity, then rerun setup. Do not use unknown scripts to alter proxies, bypass certificate checks or switch to an untrusted mirror. Distinguish Python/dependency failures from model failures.

Invalid model path / environment passes but speech fails

Check completed setup and launch normally. Verify backend, Python and model paths, not the sender's paths. Dependency checks do not prove adequate memory, decodable audio or successful inference. Try a short recording and inspect the error.

QTA / QAT import or playback fails

Retain the original and export ordinary M4A; renaming is not conversion. Container/codec support varies. Multi-track processing uses the first audio track, not spatial effects or additional layers.

AI reports 401 / 403, 429, 400 or JSON errors

401/403: key/model access; 429: credit/rate limits; 400: root URL, model ID and streamed Chat Completions JSON compatibility. For JSON/truncation, inspect diagnostics/usage rather than retrying endlessly. Configured is not authenticated; failure does not imply no charge.

Notion export fails

Check the connection token, parent page sharing and write access. An unknown previous result may already have created a page. An LLM key cannot replace a Notion token.

How do I report a problem safely?

Send OS version, CPU/chip, script name, steps, timestamp and the last error lines. Redact keys, accounts, personal paths and lecture text. Do not send .runtime, full audio or diagnostic answer text by default.

12 / First-use checklist

  • The workspace uses http://127.0.0.1, not a static HTML file.
  • Setup is for first installation/repair; launch is for daily use.
  • A short authorized recording was actually transcribed and reviewed.
  • You can distinguish audio, transcript, AI corrections and AI summaries.
  • No keys, .runtime, original audio or diagnostics were casually shared.
  • You can stop with Control+C and reopen your saved work.
