Mac + Windows · the simplest way / 一次安装，之后直接打开
  1. Unzip the entire package first. Keep the folder together.
    先完整解压，不要只打开 HTML，也不要把 .app 单独移出文件夹。
  2. Mac: double-click setup-mac.command (or the included LectureAtelier.app launcher). Windows x64: double-click setup-windows.bat.
    首次输入 y 同意联网下载：必要时自动安装项目内 Python，再装 PDF、Whisper、FFmpeg 与多语言 small 权重。无需管理员权限或 API key。下载约 0.5–1.5 GB，预留 2–4 GB 磁盘。
  3. Later: launch.command on Mac; launch-windows.bat on Windows. Keep Terminal open; stop with Control+C, not Command+C.
    以后用 launch 启动，不必重新安装。网页地址：http://127.0.0.1:8767。

Output language & video / 笔记输出语言与视频

Select Note output language independently of UI/recording language: Chinese, English, French, German, Vietnamese, Japanese or Match source. Default scene prompts follow that choice; your custom text and existing notes are preserved. 输出语言在右侧选择，“语言设置”可查看对应提示词；原文引句不翻译。

Local video transcription first extracts a reusable 16 kHz mono WAV, then starts Whisper. Original video stays intact. MP4 等视频先提取音轨、显示准备进度，再本地转写；缓存占约 110 MiB/小时。不保证整体加速幅度，详情见完整手册。

Multilingual recordings / 多语言录音

Recording language → Multilingual recording → select 2–6 languages; a French + Vietnamese preset is included. 录音语言可选“法语＋越南语”预设，或自由勾选组合。短窗识别保留原语言，不改笔记输出语言；同一句混说不保证准确，判断不足请回听。Extra local computation is required; real speech accuracy for every combination is not verified.

AI proofreading / AI 校对稿

After local Whisper transcription, click “AI proofread” beside the source transcript. Add your topic and terminology, then confirm the text-only API call. Edits appear in place: red strikeout, blue insertion, and question marks for guesses. Click an edit to accept/reject; bulk review is available. A small optional set of in-word stutters is cleaned with undo history. Numbers, negations and transcript gaps are not reconstructed from topic alone. If real timestamps and audio exist, listen or re-run local Whisper with terminology hints, compare/adopt a candidate, then re-proofread only that sentence. Hints can bias recognition and do not verify speech.

录音转写后点“AI 校对稿” → 填话题、术语 → 确认发送文字。点击彩色修改逐处接受 / 拒绝，也可一键处理；自动清理的词内口吃可撤销。疑点可局部 Whisper 补转及回听；采用候选后再核对该句。文字模型不直接听到录音。

“Export transcript editions” offers original (before this pass), marked (accepted + pending, excluding rejected) and revised (accepted only). Word, PDF, HTML, Markdown, TXT and JSON are supported; SRT supports original/revised only. Word uses native tracked changes; colors may follow the reader’s revision settings. Exporting does not call a model.

PDF, estimates & Notion

The notes panel estimates input/output tokens before each run. Unknown model rates require manual prices; an estimate is not a spending cap. Choose PDF or Word in Export. “Rates & Notion” stores a connection token and parent page ID locally; “Send to Notion” asks for confirmation before creating a new child page. Share the parent page with that connection first. Notion sends text to the cloud, never the audio or full transcript.

Security & platform notes

The Mac .app is a convenient unsigned launcher, not a notarized, self-contained binary. If macOS or Windows blocks it, do not disable security; inspect the source or ask Codex for help. Windows PowerShell script policy is respected, not bypassed. Windows x64 scripts are supplied but not Windows-machine tested; Windows ARM64 is not packaged. Local CPU Whisper small favors portability over the accuracy of large models. Existing MLX setups are preserved.

First-run installer package: models and runtime are downloaded, not pre-bundled for offline first launch. No author's recordings, notes, keys or database are included. Third-party terms and download sources are in THIRD-PARTY-NOTICES.txt. For Codex-assisted setup, read CODEX_SETUP.md.
